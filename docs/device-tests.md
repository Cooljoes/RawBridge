# 实机测试说明

请在测试记录中写下日期、设备和系统版本、相机型号、拍摄设置、导入方式、访问权限、网络设置与保存目的地。保留相机卡原片直到校验完成。可使用“有限访问”仅向测试应用开放测试照片。

## 手动刷新与格式分类

1. 首次授权后点「刷新图库」，记录「NEF」和「JPEG + NEF」的数量。打开尼康配对照片，核对同一资产里列出的 NEF 和 JPEG。
2. 退出 RawBridge，再向系统照片导入一张新照片。重新打开 RawBridge，确认仍显示上次刷新的列表。点右上角的刷新按钮，确认新照片出现在对应分组。
3. 单独筛选「NEF」，确认配对照片只出现在「JPEG + NEF」分组。在筛选结果中点「全选」，核对选择数量。
4. 有限访问时，在系统设置中移除一张已选照片。回到应用检查该项已隐藏。新增授权的照片在下一次手动刷新后显示。
5. 在至少有 101 张可访问照片的图库中，最后导入一张拍摄日期较早的照片。点刷新，在全部格式、全部相机筛选下核对各分组合计 100 张、刚导入的照片已出现、第 101 张已移出。一组 JPEG + RAW 只占一个名额。iOS 17 和 18 单独与系统「最近添加」相簿核对。
6. 在含有多种格式的结果中点标题收起、再展开同一组，核对组名、数量和照片。切换相机品牌后核对格式菜单只出现该品牌已有的格式。只有一种格式时直接通过分组标题浏览。

## Nikon USB 配对与完整性

1. 将尼康相机设为 RAW（NEF）+ JPEG，同时拍摄一张。保留同次曝光的 NEF 和 JPEG。先从卡上读取两个原文件名、字节数和 SHA-256。
2. 用数据线连接相机与 iPad，通过系统“照片”的导入流程导入。记录具体机型与系统是否将此次曝光显示为一项资产。
3. 在 RawBridge 点「刷新图库」，进入「JPEG + NEF」分组找到该项，查看同一个详情页的资源清单。记录每项的角色、UTI、原始文件名及可知的大小。验收要求为同一资产同时具有独立的 JPEG 与 NEF 原始资源。如果显示为两条独立资产，记录实际行为，并分别验证提取。
4. 先只导出 RAW，再选择另一个空目录使用 RAW + JPEG。核对输出文件数量、名称，以及两次导出的 NEF。每个输出都要与卡上的对应文件进行比较。
5. 在 RawBridge 的“设置 → 校验文件完整性”中选择存储卡上的原片与目标目录文件。记录两边的文件名、字节数与完整的 64 位十六进制摘要。也可以把导出结果复制到 Mac，执行下面的命令。两项输入需指向不同位置的对应文件。

```sh
shasum -a 256 "/Volumes/CAMERA/DCIM/100NIKON/DSC_0001.NEF" "/path/to/export/DSC_0001.NEF"
cmp "/Volumes/CAMERA/DCIM/100NIKON/DSC_0001.NEF" "/path/to/export/DSC_0001.NEF"
```

## 场景与通过条件

| 场景 | 实机操作及可检查结果 |
| --- | --- |
| 单独 NEF、单独 JPEG | 分别导入并刷新图库。在「NEF」和「JPEG」分组分别找到原片，详情显示各自资源。请求不存在格式的导出数量为零。分别导出并与卡原片比较。 |
| Apple ProRAW 与普通 DNG | 取支持 ProRAW 的 iPhone 实拍文件和普通 DNG 各一份。检查详情中的标识和元数据，确认不会把普通 DNG 误判为 ProRAW。与独立保存的原始 DNG 比对。 |
| HEIF + RAW | 取实际使用 HEIF 配对的相机样本，核对两个独立资源。仅 JPEG 模式不可将 HEIF 转码导出。 |
| 仅在 iCloud 的原片 | 在启用“优化储存”的设备上选取经确认本地缺失的原片。先关下载，记录系统错误。再开下载，记录进度与结果。若资源已被缓存，记录该条件尚未覆盖。 |
| 有限、拒绝和变更授权 | 首次拒绝后检查设置入口。改为有限并选择两项，增加和移除其中一项，核对可见列表。最后切换到完整访问。 |
| 批量与文件重名 | 选取多项含相同原文件名的照片。分别测试“保留两份”和“报告冲突”。检查已存在文件的哈希与各输出的哈希，重试仅处理未完成项。 |
| 空间不足或设备断开 | 使用可清空的测试卷及已知可用容量。目标剩余空间低于原片体积时导出，观察失败原因、成功数和最终文件名。恢复空间后重试。 |
| 取消 | 大批量写盘或 iCloud 下载过程中取消。记录当时已完成的数量，确认未完成项可重试，已完成项不重复。对所有最终命名的文件复算哈希。 |
| RAW 无法解码 | 选取设备当前确实无法预览、但图库能提供原始资源的相机文件。记录预览提示，再导出与相机卡摘要比较。 |
| 文件提供方与分享 | 分别选择“我的设备”、iCloud Drive、外接 USB 卷。从系统分享面板选取保存文件或接收应用。对接收位置里的文件重新校验。 |
| iPad 布局与窗口 | 横竖屏切换、窄窗口、两窗口同时导出同名照片。检查选择状态、进度、系统面板锚点与重名策略。 |
